# Sources du Visual Paper

Ce dossier conserve le manuscrit TeX, les figures TikZ et SVG et les données JavaScript de la version livrée. Le fichier [HTML livré](../index.html) est autonome. Les liens de navigation et de téléchargement ont été adaptés au dépôt et à GitHub Pages.

Le pipeline Pages assemble les fichiers statiques fournis. Une régénération depuis TeX demanderait les scripts et le gabarit correspondant à cette version.
